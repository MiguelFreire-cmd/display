# 🎨 Estudo de `display` no CSS

Este projeto foi criado para **estudar e praticar a propriedade `display` do CSS**, explorando seus principais valores e entendendo como eles afetam o comportamento e o posicionamento dos elementos na página.

A ideia é aprender na prática, testando diferentes situações e observando como cada `display` funciona.

## 📚 O que estou estudando?

Neste projeto, são explorados principalmente:

- `display: block`
- `display: inline`
- `display: inline-block`
- `display: flex`
- `display: grid`
- `display: none`

### `block`

O elemento ocupa toda a largura disponível e começa em uma nova linha.

```css
display: block;
````

É comum em elementos como `div`, `section` e `p`.

### `inline`

O elemento ocupa apenas o espaço necessário e permanece na mesma linha que outros elementos.

```css
display: inline;
```

É bastante utilizado para elementos pequenos dentro de um texto.

### `inline-block`

Combina características dos dois anteriores: o elemento permanece na mesma linha, mas permite definir dimensões como `width` e `height`.

```css
display: inline-block;
```

### `flex`

Facilita o alinhamento e a distribuição de elementos em uma dimensão, seja em linha ou coluna.

```css
display: flex;
```

É muito útil para criar layouts, centralizar elementos e organizar componentes.

### `grid`

Permite criar layouts baseados em linhas e colunas.

```css
display: grid;
```

É especialmente interessante para estruturas mais complexas e layouts bidimensionais.

### `none`

Remove o elemento do fluxo normal da página.

```css
display: none;
```

É útil quando queremos esconder completamente um elemento.

## 🧪 Objetivo do projeto

Mais do que decorar os valores da propriedade `display`, o objetivo é entender:

* Como cada valor altera o comportamento dos elementos;
* Quando utilizar cada tipo de `display`;
* Como eles afetam largura, altura e posicionamento;
* Como combinar `display` com outras propriedades do CSS;
* Quais situações são mais adequadas para `flex` e `grid`.
